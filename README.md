# 🛍️ ShopSphere – Product Store

A responsive production capstone project that demonstrates an interactive
e-commerce product store using HTML, CSS and JavaScript.

The application includes product management, authentication simulation,
shopping cart functionality and persistent browser storage.

## 📌 Project Overview

ShopSphere is a front-end product store application designed to demonstrate
modern JavaScript concepts and real-world web application functionality.

Users can browse products, search and filter products, add products to a
shopping cart, and manage products using CRUD operations.

The application also uses browser localStorage to maintain products,
cart information and login state.

---

## ✨ Features

### 🔐 Authentication Simulation
- Login using email and password
- Login state stored using localStorage
- Logout functionality

### 🛍️ Product Catalog
- Responsive product cards
- Product images
- Product descriptions
- Product prices
- Product categories

### 🔎 Search & Filtering
- Search products by name
- Filter products by category

### 📝 CRUD Operations
- Add new products
- View products
- Edit existing products
- Delete products

### 🛒 Shopping Cart
- Add products to cart
- View cart items
- Remove items from cart
- Calculate total price
- Checkout simulation
